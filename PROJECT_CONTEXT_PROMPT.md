# 🚀 Промпт для быстрого объяснения контекста проекта CargoSite

## 📋 О проекте

**CargoSite** — это полнофункциональная e-commerce платформа для доставки товаров из Китая в Беларусь. Проект представляет собой монохромное веб-приложение с темной темой, специализирующееся на карго-доставке товаров с китайских маркетплейсов (Pinduoduo, Taobao, 1688, GoFish, WeChat, Poizon и др.).

### Основной функционал:
- **Каталог товаров** с фильтрацией и поиском
- **Корзина и оформление заказов** с отслеживанием доставки
- **Система отслеживания** (China tracking, International tracking, Local tracking)
- **Таможенное оформление** с декларациями и статусами
- **Batch Cargo** — объединение заказов в партии для доставки
- **Профиль пользователя** с историей заказов, реферальной программой, лояльностью
- **Админ-панель** для управления товарами, заказами, промокодами, статистикой
- **Система поддержки** с тикетами и чатом
- **Telegram бот** для верификации телефона и квестов
- **Платежная система** (bePaid) для оплаты заказов
- **Интеграция с Eupost API** для доставки через Европочту

## 🎭 Анимации

### CSS анимации (`src/styles/animations.css`)

1. **float** — плавающая анимация для логотипов (3s, ease-in-out, infinite)
   - Движение вверх-вниз на 20px

2. **pulse-glow** — пульсирующее свечение (2s, ease-in-out, infinite)
   - Тень с красным свечением от 20px до 40px

3. **gradient-shift** — сдвиг градиента (3s, ease, infinite)
   - Анимированный градиентный фон

4. **slide-up** — появление снизу (0.6s, ease-out)
   - Элемент появляется снизу с прозрачностью

5. **card-hover** — эффект поднятия карточки
   - Поднятие на 8px и масштабирование до 1.02

6. **particle-float** — плавающие частицы (10s, linear, infinite)
   - Частицы движутся вверх и вправо

7. **border-glow** — свечение границ (2s, ease-in-out, infinite)
   - Граница пульсирует красным цветом

### Framer Motion анимации

**Используемые эффекты:**
- `initial={{ opacity: 0, y: 20 }}` — начальное состояние (скрыто, смещено вниз)
- `animate={{ opacity: 1, y: 0 }}` — анимация появления
- `whileHover={{ scale: 1.05, y: -2 }}` — эффект при наведении
- `whileTap={{ scale: 0.95 }}` — эффект при клике
- `transition={{ duration: 0.3 }}` — плавные переходы
- `AnimatePresence` — для анимации появления/исчезновения элементов

**Типичные паттерны:**
- Карточки товаров появляются с задержкой (stagger effect)
- Кнопки имеют hover и tap эффекты
- Модальные окна появляются с масштабированием
- Элементы появляются при скролле (Intersection Observer)

**Управление состоянием:**

**Стилизация:**
- Tailwind CSS для утилитарных классов
- CSS переменные для темы

### Backend

**Безопасность:**
- JWT аутентификация
- Spring Security с ролями (USER, ADMIN)
- BCrypt для хеширования паролей (strength 12)
- CORS конфигурация
- Security headers (XSS, CSP, HSTS)
- Валидация через Jakarta Validation

**Производительность:**
- Кэширование через Spring Cache
- Lazy loading для JPA отношений
- Query hints для оптимизации
- Пагинация для списков
- Индексы на часто используемых колонках

**Архитектура:**
- Монолитное приложение (Spring Boot)
- RESTful API
- WebSocket для real-time обновлений
- Глобальный обработчик исключений
- Централизованная конфигурация

## 🔧 Типичные задачи разработки

### Добавление нового компонента:
1. Создать компонент в `src/components/` или `src/components/ui/`
2. Использовать тему из `config/theme.js`
3. Применить Tailwind классы
4. Добавить анимации через Framer Motion при необходимости
5. Обеспечить адаптивность

### Добавление новой страницы:
1. Создать компонент в `src/pages/`
2. Добавить маршрут в соответствующий Layout
3. Использовать единый стиль (градиенты, темная тема)
4. Добавить в навигацию (Header)

### Работа с API:
1. Использовать `axiosInstance` из `api/axiosInstance.jsx`
2. Использовать React Query для кэширования
3. Обрабатывать ошибки через глобальный обработчик

### Стилизация:
1. Использовать CSS переменные из `index.css`
2. Применять Tailwind утилиты
3. Следовать цветовой палитре из темы
4. Использовать существующие анимации

# Веб-приложение для управления списком рассылки

Веб-интерфейс для управления списком чатов, в которые бот делает рассылку.

## Возможности

- 📋 Просмотр всех чатов из папок Telegram
- ✅ Отображение чатов, которые уже в списке рассылки
- ➕ Добавление чатов в список рассылки
- ➖ Удаление чатов из списка рассылки
- 🔍 Поиск чатов по названию
- 📊 Статистика: общее количество чатов и количество в списке рассылки

## Установка

2. Установите зависимости:
```bash
cd Python
pip install -r requirements_web.txt
```

   Или если виртуального окружения нет, создайте его:
```bash
cd /home/itmaibenben/Рабочий\ стол/Cursor/CargoSite
python3 -m venv telegram_bot_env
source telegram_bot_env/bin/activate

pip install -r requirements_web.txt
```

3. Убедитесь, что у вас есть файл сессии Telegram (`my_session.session`) в папке Python.

4. Убедитесь, что файл `fleamarkets_list.txt` существует в папке Python (или будет создан автоматически).

## Запуск

### Вариант 1: Использование скрипта (рекомендуется)
```bash
cd Python
./run_web.sh
```

### Вариант 2: Ручной запуск
```bash
# Активируйте виртуальное окружение
cd /home/itmaibenben/Рабочий\ стол/Cursor/CargoSite
source telegram_bot_env/bin/activate

# Запустите приложение
cd Python
python web_app.py
```

Веб-приложение будет доступно по адресу: `http://localhost:5000`

Для доступа с других устройств в сети используйте тот же способ (приложение уже настроено на `0.0.0.0:5000`)

## Использование

1. Откройте браузер и перейдите по адресу `http://localhost:5000`
2. Нажмите кнопку "🔄 Обновить список" для загрузки всех чатов из папок Telegram
3. Используйте поиск для быстрого нахождения нужных чатов
4. Нажмите "Добавить" для добавления чата в список рассылки
5. Нажмите "Удалить" для удаления чата из списка рассылки

## Структура файлов

- `web_app.py` - основное Flask приложение
- `templates/index.html` - HTML интерфейс
- `static/style.css` - стили
- `static/script.js` - JavaScript для интерактивности
- `fleamarkets_list.txt` - файл со списком чатов для рассылки (обновляется автоматически)

## Настройка папок

По умолчанию приложение ищет чаты в папках:
- Барахолка 1
- Барахолка 2
- барахолка 1
- барахолка 2

Чтобы изменить список папок, отредактируйте переменную `TARGET_FOLDERS` в файле `web_app.py`:

```python
TARGET_FOLDERS = ['Ваша папка 1', 'Ваша папка 2']
```

## Примечания

- Приложение использует те же учетные данные Telegram, что и основной бот
- Убедитесь, что сессия Telegram авторизована перед использованием
- Изменения в списке рассылки сохраняются в файл `fleamarkets_list.txt` немедленно

# Документация по сущностям (Entities)

Этот документ описывает все сущности базы данных, их поля и их назначение.

---

## 1. User (Пользователь)

**Таблица:** `users`  
**Описание:** Основная сущность пользователя системы. Реализует интерфейс `UserDetails` для Spring Security.

### Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `email` | `String` | Email пользователя (первичный ключ) |
| `username` | `String` | Имя пользователя |
| `password` | `String` | Хешированный пароль |
| `phone` | `String` | Номер телефона (опционально) |
| `company` | `String` | Название компании (опционально) |
| `role` | `String` | Роль пользователя (USER, ADMIN и т.д.) |
| `referralCode` | `String` | Реферальный код пользователя (опционально) |
| `referralCount` | `Integer` | Количество приглашенных пользователей (по умолчанию: 0) |
| `discountPercent` | `Float` | Постоянная скидка пользователя в процентах (по умолчанию: 0.0) |
| `temporaryDiscountPercent` | `Float` | Временная скидка в процентах (по умолчанию: 0.0) |
| `temporaryDiscountExpired` | `LocalDateTime` | Дата истечения временной скидки (опционально) |
| `createdAt` | `LocalDateTime` | Дата регистрации пользователя (опционально) |
| `moneySpent` | `Double` | Общая сумма потраченных средств (опционально) |
| `notificationsEnabled` | `Boolean` | Включены ли уведомления (по умолчанию: false) |
| `twoFactorEnabled` | `Boolean` | Включена ли двухфакторная аутентификация (по умолчанию: false) |
| `avatarUrl` | `String` | URL аватара пользователя (опционально) |
| `emailVerified` | `Boolean` | Подтвержден ли email (по умолчанию: false) |
| `phoneVerified` | `Boolean` | Подтвержден ли телефон (по умолчанию: false) |
| `telegramUserId` | `String` | ID пользователя в Telegram (опционально) |
| `telegramVerified` | `Boolean` | Подтвержден ли Telegram (по умолчанию: false) |

### Связи

- `referredBy` (`ManyToOne`) - Пользователь, который пригласил текущего пользователя
- `referrals` (`OneToMany`) - Список пользователей, приглашенных текущим пользователем
- `questProgresses` (`OneToMany`) - Прогресс выполнения квестов пользователем

### Методы

- `getTotalDiscount()` - Возвращает общую скидку (постоянная + временная, с проверкой срока действия)
- `verifyDiscount()` - Проверяет и обнуляет временную скидку, если она истекла
- `addDiscountPercent(float)` - Добавляет постоянную скидку (максимум 20%)
- `addTemporaryDiscountPercent(float)` - Добавляет временную скидку (максимум 80%, срок 2 месяца)
- `incrementReferralCount()` - Увеличивает счетчик рефералов

## 2. Product (Товар)

**Таблица:** `products`  
**Описание:** Товары, доступные для заказа из Китая.

### Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `String` | Уникальный идентификатор товара (первичный ключ, UUID) |
| `name` | `String` | Название товара |
| `url` | `String` | URL товара на платформе (например, Taobao, 1688) |
| `price` | `Float` | Цена товара (должна быть >= 0) |
| `imageUrl` | `String` | URL изображения товара (опционально) |
| `status` | `String` | Статус товара: ACTIVE, PENDING, VERIFIED, INACTIVE (по умолчанию: ACTIVE) |
| `salesCount` | `Integer` | Количество продаж (по умолчанию: 0) |
| `cluster` | `Integer` | Кластер товара для группировки (опционально) |
| `description` | `String` | Описание товара (опционально) |
| `lastUpdated` | `Timestamp` | Дата последнего обновления (автоматически при создании) |
| `totalReviewSumm` | `Integer` | Сумма всех оценок (для расчета среднего) (по умолчанию: 0) |
| `reviewQuantity` | `Integer` | Количество отзывов (по умолчанию: 0) |
| `originCountry` | `String` | Страна происхождения (по умолчанию: "China") |
| `customsCode` | `String` | HS код для таможенной классификации (опционально) |
| `weightKg` | `Float` | Вес товара в килограммах (опционально) |
| `lengthCm` | `Float` | Длина в сантиметрах (опционально) |
| `widthCm` | `Float` | Ширина в сантиметрах (опционально) |
| `heightCm` | `Float` | Высота в сантиметрах (опционально) |
| `supplierName` | `String` | Название поставщика в Китае (опционально) |
| `supplierContact` | `String` | Контакты поставщика (опционально) |
| `estimatedDeliveryDays` | `Integer` | Примерное количество дней доставки из Китая (опционально) |

### Связи

- `reviews` (`OneToMany`) - Отзывы о товаре

### Методы

- `addReview(Integer)` - Добавляет отзыв и обновляет агрегированную статистику
- `getAverageRating()` - Возвращает средний рейтинг (0.0 если нет отзывов)
- `getVolumeWeight()` - Рассчитывает объемный вес для доставки: (длина × ширина × высота) / 5000
- `getChargeableWeight()` - Возвращает оплачиваемый вес (максимум из фактического и объемного)

## 3. Order (Заказ)

**Таблица:** `orders`  
**Описание:** Заказ пользователя на товары из Китая с полной информацией о доставке и таможне.

### Поля

#### Основные поля

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Long` | Уникальный идентификатор заказа (первичный ключ) |
| `orderNumber` | `String` | Номер заказа (уникальный, до 50 символов) |
| `dateCreated` | `Timestamp` | Дата создания заказа (автоматически) |
| `status` | `String` | Статус заказа: PENDING, VERIFIED, ITEMS_PROCESSED, SHIPPED, IN_TRANSIT, DELIVERED, COMPLETED, REFUSED, CANCELLED, REFUNDED (по умолчанию: PENDING) |
| `reasonRefusal` | `String` | Причина отказа в заказе (опционально) |

#### Поля ценообразования

| Поле | Тип | Описание |
|------|-----|----------|
| `totalClientPrice` | `Float` | Общая цена для клиента (должна быть >= 0) |
| `supplierCost` | `Float` | Стоимость поставщика (>= 0, опционально) |
| `customsDuty` | `Float` | Таможенная пошлина (>= 0, опционально) |
| `shippingCost` | `Float` | Стоимость доставки (>= 0, опционально) |
| `insuranceCost` | `Float` | Стоимость страховки (>= 0, опционально) |
| `insurance` | `Boolean` | Приобретена ли страховка (по умолчанию: false) |
| `discountApplied` | `Float` | Примененная скидка по промокоду (>= 0, опционально) |
| `userDiscountApplied` | `Float` | Примененная скидка пользователя (>= 0, опционально) |
| `discountType` | `String` | Тип скидки (опционально) |
| `discountValue` | `Float` | Значение скидки (>= 0, опционально) |

#### Поля оплаты

| Поле | Тип | Описание |
|------|-----|----------|
| `paymentMethod` | `String` | Способ оплаты: NO_BALANCE (обычная оплата) |

#### Поля доставки и отслеживания

| Поле | Тип | Описание |
|------|-----|----------|
| `deliveryAddress` | `String` | Адрес доставки (до 500 символов) |
| `trackingNumber` | `String` | Основной трек-номер (до 100 символов, опционально) |
| `chinaTrackingNumber` | `String` | Трек-номер от китайского перевозчика (до 100 символов, опционально) |
| `internationalTrackingNumber` | `String` | Трек-номер международной доставки (до 100 символов, опционально) |
| `localTrackingNumber` | `String` | Трек-номер местной доставки (до 100 символов, опционально) |

#### Поля веса и размеров

| Поле | Тип | Описание |
|------|-----|----------|
| `weight` | `Float` | Общий вес заказа в кг (>= 0, опционально) |
| `volumeWeight` | `Float` | Объемный вес для расчета доставки (>= 0, опционально) |
| `chargeableWeight` | `Float` | Оплачиваемый вес (максимум из фактического и объемного) (>= 0, опционально) |

#### Поля таможни и документов

| Поле | Тип | Описание |
|------|-----|----------|
| `customsDeclarationNumber` | `String` | Номер таможенной декларации (до 100 символов, опционально) |
| `customsStatus` | `String` | Статус таможни: PENDING, CLEARED, HELD, REJECTED (опционально) |
| `customsClearanceDate` | `Timestamp` | Дата таможенного оформления (опционально) |
| `customsValue` | `Float` | Заявленная стоимость для таможни (>= 0, опционально) |

#### Даты доставки

| Поле | Тип | Описание |
|------|-----|----------|
| `shippedFromChinaDate` | `Timestamp` | Дата отправки из Китая (опционально) |
| `arrivedAtCustomsDate` | `Timestamp` | Дата прибытия на таможню (опционально) |
| `estimatedDeliveryDate` | `Timestamp` | Ожидаемая дата доставки (опционально) |
| `actualDeliveryDate` | `Timestamp` | Фактическая дата доставки (опционально) |

#### Информация о перевозчике

| Поле | Тип | Описание |
|------|-----|----------|
| `carrierName` | `String` | Название перевозчика (EMS, DHL, China Post и т.д.) (до 100 символов, опционально) |
| `carrierService` | `String` | Тип услуги перевозчика (Express, Standard и т.д.) (до 100 символов, опционально) |

### Связи

- `user` (`ManyToOne`) - Пользователь, сделавший заказ
- `items` (`OneToMany`) - Список товаров в заказе
- `promocode` (`ManyToOne`) - Примененный промокод (опционально)
- `batchCargo` (`ManyToOne`) - Пакетный груз, к которому относится заказ (опционально)

### Методы

- `calculateTotalWeight()` - Рассчитывает общий вес заказа из товаров
- `isTerminalState()` - Проверяет, находится ли заказ в финальном состоянии (COMPLETED, CANCELLED, REFUNDED)
- `canBeCancelled()` - Проверяет, можно ли отменить заказ

## 4. OrderItem (Позиция заказа)

**Таблица:** `order_items`  
**Описание:** Отдельный товар в заказе с информацией о покупке и доставке из Китая.

### Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Long` | Уникальный идентификатор позиции (первичный ключ) |
| `quantity` | `Integer` | Количество товара (>= 1) |
| `priceAtTime` | `Float` | Цена товара на момент заказа (>= 0) |
| `supplierPrice` | `Float` | Фактическая цена, уплаченная поставщику в Китае (>= 0, опционально) |
| `trackingNumber` | `String` | Индивидуальный трек-номер товара (до 100 символов, опционально) |
| `chinaTrackingNumber` | `String` | Трек-номер от китайского поставщика (до 100 символов, опционально) |
| `purchaseStatus` | `String` | Статус покупки: PENDING, PURCHASED, NOT_PURCHASED, REFUNDED (по умолчанию: PENDING) |
| `purchaseRefusalReason` | `String` | Причина отказа в покупке товара (опционально) |
| `purchasedDate` | `Timestamp` | Дата покупки товара у поставщика (опционально) |
| `chinaDeliveryPrice` | `Float` | Стоимость доставки от поставщика до склада (>= 0, опционально) |
| `itemWeight` | `Float` | Вес товара (количество × вес товара) (>= 0, опционально) |
| `itemCustomsValue` | `Float` | Заявленная стоимость для таможни для этого товара (>= 0, опционально) |

### Связи

- `order` (`ManyToOne`) - Заказ, к которому относится позиция
- `orderHistory` (`ManyToOne`) - История заказа (опционально)
- `product` (`ManyToOne`) - Товар

### Методы

- `getTotalPrice()` - Рассчитывает общую цену позиции (количество × цена на момент заказа)
- `getTotalSupplierCost()` - Рассчитывает общую стоимость поставщика для позиции
- `isPurchased()` - Проверяет, был ли товар куплен
- `isPurchaseRefused()` - Проверяет, был ли отказ в покупке

## 8. BatchCargo (Пакетный груз)

**Таблица:** `batch_cargos`  
**Описание:** Группировка нескольких заказов для консолидированной доставки и таможенного оформления из Китая.

### Поля

#### Основные поля

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `Long` | Уникальный идентификатор (первичный ключ) |
| `creationDate` | `Timestamp` | Дата создания пакета (автоматически, неизменяемая) |
| `purchaseDate` | `Timestamp` | Дата покупки товаров у поставщиков |
| `status` | `String` | Статус: UNFINISHED, FINISHED, REFUSED, IN_TRANSIT, AT_CUSTOMS, DELIVERED (по умолчанию: UNFINISHED) |
| `reasonRefusal` | `String` | Причина отказа (опционально) |

#### Поля отслеживания и логистики

| Поле | Тип | Описание |
|------|-----|----------|
| `batchTrackingNumber` | `String` | Основной трек-номер пакета (уникальный, до 100 символов, опционально) |
| `chinaWarehouseAddress` | `String` | Адрес склада в Китае (до 500 символов, опционально) |
| `consolidationWarehouse` | `String` | Название склада консолидации (до 255 символов, опционально) |
| `shippingMethod` | `String` | Способ доставки: Air, Sea, Express и т.д. (до 100 символов, опционально) |
| `carrierName` | `String` | Название перевозчика для пакета (до 100 символов, опционально) |
| `estimatedArrivalDate` | `Timestamp` | Ожидаемая дата прибытия в страну назначения (опционально) |
| `actualArrivalDate` | `Timestamp` | Фактическая дата прибытия (опционально) |

#### Поля таможни

| Поле | Тип | Описание |
|------|-----|----------|
| `customsDeclarationNumber` | `String` | Номер таможенной декларации пакета (до 100 символов, опционально) |
| `customsStatus` | `String` | Статус таможни: PENDING, CLEARED, HELD, REJECTED (опционально) |
| `customsClearanceDate` | `Timestamp` | Дата таможенного оформления (опционально) |
| `totalBatchWeight` | `Float` | Общий вес пакета в кг (опционально) |
| `totalBatchValue` | `Float` | Общая заявленная стоимость для таможни (опционально) |

#### Метаданные пакета

| Поле | Тип | Описание |
|------|-----|----------|
| `photoUrl` | `String` | URL фото консолидированного пакета (опционально) |
| `description` | `String` | Описание/примечания к пакету (опционально) |
| `itemCount` | `Integer` | Количество товаров в пакете (опционально) |
| `orderCount` | `Integer` | Количество заказов в пакете (опционально) |

### Связи

- `orders` (`OneToMany`) - Список заказов в пакете

### Методы

- `getTotalOrderCount()` - Возвращает общее количество заказов в пакете
- `calculateTotalWeight()` - Рассчитывает общий вес из всех заказов
- `isTerminalState()` - Проверяет, находится ли пакет в финальном состоянии
- `canBeModified()` - Проверяет, можно ли еще изменять пакет

### Поля

## Enum-классы

### DiscountType

Типы скидок для промокодов:
- `PERCENTAGE` - Процентная скидка
- `FIXED` - Фиксированная сумма скидки

### TicketStatus

Статусы тикетов поддержки:
- `OPEN` - Открыт
- `IN_PROGRESS` - В работе
- `CLOSED` - Закрыт

### RewardType

Типы наград за квесты:
- `TEMPORARY` - Временная награда
- `PERMANENT` - Постоянная награда

### QuestConditionType

Типы условий для квестов:
- `INVITE` - Пригласить друга
- `PURCHASE` - Совершить покупку
- `REVIEW` - Оставить отзыв после выполненного заказа
- `SPENT` - Потратить определенное количество средств
- `QUANTITY_ORDER` - Количество заказов
- `TELEGRAM` - Подписаться на Telegram

## Примечания

1. Все денежные суммы хранятся в формате `Float` или `Double` (¥ юани).
2. Даты используют `Timestamp` (для точности до миллисекунд) или `LocalDateTime`.
3. Связи `ManyToOne` и `OneToMany` используют `LAZY` загрузку по умолчанию для оптимизации.
4. Поля с суффиксом `AtTime` хранят снимок состояния на момент создания (например, `priceAtTime`).
5. Статусы хранятся как строки для гибкости, но должны соответствовать определенным значениям.

## Структура навигации

```
AppNavigator
├── Guest (неавторизован)
│   ├── GuestTabs (Home, Catalog, Заказать, Calculator, News)
│   ├── Login/Register
│   └── Дополнительные экраны (ProductDetail, Reviews, etc.)
│
├── User (авторизован)
│   ├── AppTabs (Home, Catalog, Cart, Profile)
│   └── Все экраны пользователя
│
└── Admin (администратор)
    ├── AdminDrawer (все админ функции)
    └── Детальные экраны
```

## API настройка

API настроен на `localhost:8080/api` как требовалось.

Для работы на физическом устройстве измените в `src/api/axiosInstance.js`:
```javascript
const BASE_URL = __DEV__ 
  ? 'http://ВАШ_IP:8080/api'  // Замените на IP вашего компьютера
  : 'https://fluvion.by/api';
```

## Запуск

```bash
cd Mobile
npx expo start --clear
```

Затем:
- Нажмите `a` для Android
- Нажмите `i` для iOS
- Или отсканируйте QR-код в Expo Go

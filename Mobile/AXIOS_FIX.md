# Исправление проблемы с axios

## Проблема
Axios пытается использовать Node.js модуль `crypto`, который недоступен в React Native.

## Решение
Создан файл `metro.config.js`, который настраивает Metro Bundler для использования браузерной версии axios вместо Node.js версии.

## Что было сделано
1. ✅ Создан `metro.config.js` с настройкой резолвера для axios
2. ✅ Настроен резолвер для использования `axios/dist/axios.js` (браузерная версия)
3. ✅ Кэш очищен

## Перезапуск
После изменений необходимо перезапустить сервер с очисткой кэша:

```bash
npx expo start --clear
```

Или остановите текущий сервер (Ctrl+C) и запустите заново:

```bash
npm start -- --clear
```

## Альтернативное решение
Если проблема сохраняется, можно использовать `react-native-axios` или `fetch` API вместо axios.

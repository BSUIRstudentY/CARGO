# 🎉 Мобильное приложение Fluvion - Полная версия

## ✅ ВСЁ ГОТОВО!

Мобильное приложение полностью повторяет функциональность веб-версии с поддержкой GuestLayout, AppLayout и AdminLayout.

## 📱 Структура приложения

### GuestLayout (Неавторизованные пользователи)
- ✅ Просмотр каталога
- ✅ Просмотр товаров
- ✅ Калькулятор стоимости
- ✅ Новости
- ✅ Отзывы
- ✅ Доставка и оплата
- ✅ FAQ
- ✅ Поддержка
- ✅ Курс доставки
- ✅ Заказать товар (MultiTerminal)
- ✅ Вход/Регистрация

### AppLayout (Авторизованные пользователи)
- ✅ Все функции GuestLayout +
- ✅ Корзина
- ✅ Заказы
- ✅ Профиль
- ✅ Уведомления
- ✅ Самовыкуп
- ✅ Сборные грузы
- ✅ Инструкции по заказу

### AdminLayout (Администраторы)
- ✅ Dashboard
- ✅ Управление пользователями
- ✅ Управление заказами
- ✅ Управление товарами
- ✅ Управление тикетами
- ✅ Управление новостями
- ✅ Управление промокодами
- ✅ Управление квестами
- ✅ Управление батч-карго
- ✅ Управление каталогом
- ✅ Статистика

## 🔧 Технические детали

### API
- **URL**: `http://localhost:8080/api` (для разработки)
- **Кэширование**: React Query (как в веб-версии)
- **Токены**: AsyncStorage (аналог localStorage)

### Навигация
- **Guest**: Bottom Tabs
- **User**: Bottom Tabs
- **Admin**: Drawer Navigation

## 🚀 Запуск

```bash
cd Mobile
npx expo start --clear
```

Затем:
- Нажмите `a` для Android
- Нажмите `i` для iOS
- Или отсканируйте QR-код в Expo Go

## 📝 Настройка для физического устройства

Если запускаете на физическом устройстве, измените IP в `src/api/axiosInstance.js`:

```javascript
const BASE_URL = __DEV__ 
  ? 'http://192.168.X.X:8080/api'  // IP вашего компьютера
  : 'https://fluvion.by/api';
```

Узнать IP:
```bash
hostname -I  # Linux
ipconfig     # Windows
```

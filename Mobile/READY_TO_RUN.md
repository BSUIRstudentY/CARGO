```bash

```

### Шаг 2: Запустите на Android

Когда сервер запустится, нажмите:
```
a
```

Или в новом терминале:
```bash
npm run android
```

## ⚙️ Настройка IP адреса (если нужно)

Если приложение не может подключиться к API:

1. Узнайте IP вашего компьютера:
   ```bash
   hostname -I
   ```

2. Откройте `src/api/axiosInstance.js`

3. Замените IP в строке:
   ```javascript
   const BASE_URL = __DEV__ 
     ? 'http://ВАШ_IP:8080/api'  // Замените на ваш IP
     : 'https://fluvion.by/api';
   ```

4. Перезапустите сервер

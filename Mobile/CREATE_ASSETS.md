# Создание ресурсов для приложения

## Проблема: Отсутствуют файлы иконок

Приложение требует следующие файлы в папке `assets/`:
- `icon.png` - иконка приложения (1024x1024px)
- `splash.png` - экран загрузки (1242x2436px для iOS, 1080x1920px для Android)
- `adaptive-icon.png` - адаптивная иконка для Android (1024x1024px)
- `favicon.png` - иконка для веб-версии (48x48px)

## Быстрое решение

### Вариант 1: Использовать временные изображения

Создайте простые изображения или скачайте готовые:

```bash
cd Mobile/assets

# Создайте простую иконку (можно использовать любой PNG редактор)
# Или скачайте готовую иконку Fluvion
```

### Вариант 2: Временно отключить иконки

Измените `app.json`:

```json
{
  "expo": {
    "icon": null,
    "splash": {
      "image": null
    }
  }
}
```

### Вариант 3: Использовать онлайн генератор

1. Перейдите на https://www.appicon.co/
2. Загрузите вашу иконку
3. Скачайте все размеры
4. Поместите файлы в папку `assets/`

## Рекомендуемые размеры

- **icon.png**: 1024x1024px
- **splash.png**: 1242x2436px (iOS) или 1080x1920px (Android)
- **adaptive-icon.png**: 1024x1024px (Android)
- **favicon.png**: 48x48px или 192x192px

## Временное решение

Пока вы не создали иконки, можно использовать простые цветные квадраты или логотип Fluvion.

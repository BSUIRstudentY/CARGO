# Руководство по запуску мобильного приложения

## ✅ Все проблемы исправлены!

Версии зависимостей обновлены и совместимы с Expo 49.

## Быстрый старт

### 1. Запуск сервера разработки

```bash
cd Mobile
npm start
```

Это запустит Metro Bundler и покажет QR-код.

### 2. Запуск на устройстве

#### Вариант A: Использование Expo Go (Рекомендуется)

1. **Установите Expo Go** на ваш телефон:
   - 📱 iOS: [App Store](https://apps.apple.com/app/expo-go/id982107779)
   - 🤖 Android: [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)

2. **Отсканируйте QR-код**:
   - iOS: Используйте встроенную камеру
   - Android: Используйте приложение Expo Go

3. Приложение автоматически откроется на вашем устройстве!

#### Вариант B: Веб-браузер (для тестирования)

```bash
npm run web
```

Приложение откроется в браузере по адресу `http://localhost:19006`

## Команды

```bash
# Запуск сервера разработки
npm start

# Запуск для iOS (требуется Mac и Xcode)
npm run ios

# Запуск для Android (требуется Android SDK)
npm run android

# Запуск для веб
npm run web
```

## Решение проблем

### Проблема: "Port 8081 is running"

Если порт занят, Expo предложит использовать другой порт. Просто нажмите `yes`.

### Проблема: "Android SDK not found"

Это нормально, если вы не настроили Android Studio. Используйте **Expo Go** на физическом устройстве - это проще и быстрее!

### Проблема: Зависимости несовместимы

Если видите предупреждения о несовместимости:

```bash
npx expo install --fix
```

Это автоматически исправит все версии.

### Проблема: Приложение не загружается

1. Убедитесь, что телефон и компьютер в одной Wi-Fi сети
2. Проверьте, что Spring Boot сервер запущен
3. Обновите приложение в Expo Go (потяните вниз)

## Настройка API

Перед запуском убедитесь, что:

1. Spring Boot сервер запущен на `http://localhost:8080` или `https://fluvion.by`
2. В файле `src/api/axiosInstance.js` указан правильный `BASE_URL`

Для разработки на физическом устройстве используйте IP-адрес вашего компьютера вместо `localhost`.

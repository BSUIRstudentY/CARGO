# Настройка переменных окружения

Файл `.env` создан в корне проекта Spring Boot со всеми необходимыми переменными.

## Использование в IntelliJ IDEA

Чтобы IntelliJ IDEA загружала переменные из `.env` файла автоматически, вам нужно:

### Вариант 1: Использовать плагин EnvFile

1. Установите плагин **EnvFile** через Settings → Plugins
2. В Run Configuration добавьте:
   - Нажмите на вашу конфигурацию запуска (Run → Edit Configurations)
   - Нажмите на "+" и выберите "EnvFile"
   - Укажите путь к файлу: `.env`
   - Сохраните

### Вариант 2: Вручную скопировать переменные в Run Configuration

1. Откройте Run → Edit Configurations
2. Найдите вашу конфигурацию (например, DemoApplication)
3. В разделе "Environment variables" нажмите на значок папки
4. Скопируйте все переменные из файла `.env` в формате:
   ```
   DB_HOST=localhost;DB_PORT=3306;DB_NAME=CargoDB;...
   ```
   Или добавьте каждую переменную отдельно

### Вариант 3: Использовать скрипт для загрузки

Создайте скрипт запуска `run.sh`:

```bash
#!/bin/bash
set -a
source .env
set +a
mvn spring-boot:run
```

## Важно для безопасности

⚠️ **Файл `.env` содержит чувствительные данные (пароли, секретные ключи).**

Убедитесь, что файл `.env` добавлен в `.gitignore`:

```
.env
*.env
```

Это предотвратит случайную отправку секретов в репозиторий.

## Проверка

После настройки переменных окружения, приложение должно успешно подключаться к базе данных и запускаться без ошибок аутентификации.

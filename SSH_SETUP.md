# Настройка SSH для деплоя

## Проблема: "Network is unreachable" или требуется пароль

Если при запуске скрипта деплоя вы видите ошибки подключения, это может быть связано с настройками SSH.

## Решения

### Вариант 1: Использование пароля (простой способ)

Скрипт поддерживает интерактивный ввод пароля. Просто запустите:

```bash
./deploy-telegram-advertiser.sh
```

И вводите пароль при каждом запросе.

### Вариант 2: Автоматическая передача пароля (sshpass)

Если не хотите вводить пароль каждый раз:

1. **Установите sshpass:**
   ```bash
   sudo apt install sshpass
   ```

2. **Установите переменную окружения с паролем:**
   ```bash
   export SSHPASS='ваш-пароль-для-root'
   ```

3. **Запустите скрипт:**
   ```bash
   ./deploy-telegram-advertiser.sh
   ```

⚠️ **Внимание:** Пароль будет виден в истории команд. Используйте этот метод только на безопасных системах.

### Вариант 3: Настройка SSH ключей (рекомендуется)

Это самый безопасный способ:

1. **Создайте SSH ключ (если его нет):**
   ```bash
   ssh-keygen -t ed25519 -C "your_email@example.com"
   ```

2. **Скопируйте публичный ключ на сервер:**
   ```bash
   ssh-copy-id root@212.116.115.112
   ```
   
   Или вручную:
   ```bash
   cat ~/.ssh/id_ed25519.pub | ssh root@212.116.115.112 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
   ```

3. **Проверьте подключение:**
   ```bash
   ssh root@212.116.115.112
   ```
   
   Должно подключиться без пароля.

4. **Запустите скрипт деплоя:**
   ```bash
   ./deploy-telegram-advertiser.sh
   ```

## Проверка подключения

Перед запуском скрипта проверьте подключение:

```bash
# Проверка ping
ping -c 3 212.116.115.112

# Проверка SSH
ssh root@212.116.115.112 "echo 'SSH работает'"
```

## Частые проблемы

### "Permission denied (publickey,password)"

**Решение:**
- Убедитесь, что используете правильный пароль
- Проверьте, что пользователь `root` может подключаться по SSH
- На некоторых серверах root отключен - используйте другого пользователя

### "Connection refused"

**Решение:**
- Проверьте, что SSH сервис запущен на сервере
- Проверьте, что порт 22 открыт в файрволе
- Убедитесь, что IP адрес правильный

### "Network is unreachable"

**Решение:**
- Проверьте интернет-соединение
- Проверьте, что сервер доступен: `ping 212.116.115.112`
- Возможно, сервер находится за NAT/VPN

## Изменение пользователя

Если на сервере используется не `root`, измените в скрипте:

```bash
SERVER_USER="ваш-пользователь"
```

## Безопасность

⚠️ **Важные рекомендации:**

1. **Не храните пароли в скриптах** - используйте переменные окружения или SSH ключи
2. **Используйте SSH ключи** вместо паролей для продакшена
3. **Ограничьте доступ** к файлам с паролями: `chmod 600 файл-с-паролем`
4. **Используйте отдельного пользователя** с ограниченными правами вместо root

## Альтернатива: Ручной деплой

Если автоматический деплой не работает, можно развернуть вручную:

1. Подключитесь к серверу:
   ```bash
   ssh root@212.116.115.112
   ```

2. Следуйте инструкциям из `DEPLOY_TELEGRAM_ADVERTISER.md`

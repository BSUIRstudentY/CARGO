# Быстрое решение: SQLite не попадает в JAR

## ✅ Что исправлено:

1. **`pom.xml`** - добавлены исключения для SQLite файлов при сборке
2. **`deploy.sh`** - добавлена проверка JAR перед отправкой на сервер
3. **`verify-jar.sh`** - утилита для проверки JAR файла

## 🚀 Как использовать:

### 1. Соберите проект:

```bash
cd "Spring Boot"
./mvnw clean package -DskipTests
```

### 2. Проверьте JAR (опционально):

```bash
./verify-jar.sh target/demo-0.0.1-SNAPSHOT.jar
```

Должно показать: `✅ SQLite файлы не найдены`

### 3. Задеплойте:

```bash
./deploy.sh
```

Скрипт автоматически проверит, что SQLite НЕ в JAR, и только потом отправит на сервер.

## ⚠️ Если скрипт находит SQLite в JAR:

1. Убедитесь, что `pom.xml` обновлен (должны быть исключения)
2. Очистите проект: `./mvnw clean`
3. Пересоберите: `./mvnw package -DskipTests`
4. Проверьте снова: `./verify-jar.sh target/demo-0.0.1-SNAPSHOT.jar`

## 📝 Важно:

- SQLite файл (`data/cargodb.sqlite`) остается только на вашем компьютере
- Он НЕ попадает в JAR при сборке
- На сервере используется MySQL из docker-compose
- Скрипт деплоя проверяет это автоматически

## 🔍 Ручная проверка:

```bash
# Проверить содержимое JAR
jar -tf target/demo-0.0.1-SNAPSHOT.jar | grep -i sqlite

# Должно вернуть пустой результат (SQLite не найден)
```

# Обновление списка чатов

## Как обновить список чатов на сервере

### Вариант 1: Через scp (простой способ)

```bash
# Скопируйте новый файл fleamarkets_list.txt на сервер
scp fleamarkets_list.txt root@212.116.115.112:/root/telegram_advertiser/
```

### Вариант 2: Через скрипт copy-files-to-server.sh

```bash
# Убедитесь, что файл fleamarkets_list.txt обновлен локально
./copy-files-to-server.sh
```

### Вариант 3: Вручную на сервере

```bash
# Подключитесь к серверу
ssh root@212.116.115.112

# Отредактируйте файл
nano /root/telegram_advertiser/fleamarkets_list.txt

# Или замените файл полностью
# (скопируйте содержимое нового списка)
```

## Формат файла fleamarkets_list.txt

Файл должен содержать список чатов в формате:
```
Название чата: chat_id
Название чата 2: chat_id_2
```

Пример:
```
Маркетплейс Беларусь Минск: 2388742658
Куплю/Продаю/Отдаю/Меняю/Предлагаю: 2094402328
FRAUDE | Продажа личных вещей: 1821866358
```

## После обновления списка

### Если бот запущен через systemd:

```bash
# Перезапустите сервис
ssh root@212.116.115.112 "systemctl restart telegram-advertiser"
```

### Если бот запущен вручную:

Остановите бота (Ctrl+C) и запустите снова:
```bash
cd /root/telegram_advertiser
source telegram_advertiser_env/bin/activate  # если используете venv
python telegram_advertiser.py
```

## Проверка обновления

```bash
# На сервере проверьте количество чатов в файле
ssh root@212.116.115.112 "wc -l /root/telegram_advertiser/fleamarkets_list.txt"

# Проверьте логи бота
ssh root@212.116.115.112 "journalctl -u telegram-advertiser -n 20"
```

## Важные моменты

- Бот автоматически подписывается на каналы, которые требуют подписки
- Бот отправляет сообщения в 35 случайных чатов из списка
- Интервал между отправками: 30 минут
- Попытки, где требуется подписка, но подписаться не удалось, не засчитываются

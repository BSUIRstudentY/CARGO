## Использование новых компонентов

## Цветовая схема

- **Основной акцент**: `#e81e2d` (красный) - Китай
- **Вторичный акцент**: `#407CFF` (синий) - Надежность
- **Фон**: `#0a0a0a` → `#1a1a1a` → `#2F2F2F` (градиенты)
- **Текст**: `#ffffff` → `#cdcdcd` → `#808080` (иерархия)
- **Границы**: `#333333` → `#555555` (при hover)

## Эффекты

1. **Hover эффекты**: Поднятие, масштабирование, свечение
2. **Градиенты**: Плавные переходы цветов
3. **Партиклы**: Анимированные частицы на фоне
4. **Параллакс**: Эффект глубины при движении мыши
5. **Конфетти**: При добавлении в корзину

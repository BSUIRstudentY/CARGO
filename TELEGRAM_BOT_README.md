# Инструкция по использованию Telegram бота

## Настройка

1. **Виртуальное окружение** уже создано: `telegram_bot_env/`

2. **Установка зависимостей**:
```bash
source telegram_bot_env/bin/activate
pip install -r requirements.txt
```

3. **Настройка бота**:
   - Откройте `main.py`
   - Убедитесь, что `BOT_TOKEN` правильный
   - Убедитесь, что `CHANNEL_ID` правильный (например, `@FLUVIONN`)
   - Убедитесь, что `BACKEND_URL` указывает на ваш Spring Boot сервер
   - Убедитесь, что `SITE_URL` правильный

4. **Получение имени бота**:
   - Откройте Telegram и найдите @BotFather
   - Отправьте команду `/mybots`
   - Выберите вашего бота
   - Скопируйте имя бота (например, `FLUVIONN_BOT`)
   - Обновите `botUsername` в `React/src/components/PersonalDataTab.jsx`

## Запуск бота

```bash
source telegram_bot_env/bin/activate
python main.py
```

## Функционал

### 1. Квест подписки на канал
- Пользователь подписывается на канал
- Вводит реферальный код с сайта
- Получает скидку
- **При отписке от канала скидка автоматически аннулируется**

### 2. Верификация телефона
- Пользователь нажимает "Верифицировать" на сайте
- Открывается Telegram бот
- Пользователь нажимает "Поделиться номером телефона"
- Получает код верификации
- Вводит код
- **Номер телефона привязывается к аккаунту (1 номер = 1 аккаунт)**

## API Endpoints (Backend)

### POST `/api/telegram`
Верификация Telegram через реферальный код

### POST `/api/telegram/unsubscribe`
Отмена квеста при отписке от канала

### POST `/api/telegram/request-phone-verification`
Запрос кода верификации телефона

### POST `/api/telegram/confirm-phone-verification`
Подтверждение верификации телефона с номером

## Важные моменты

1. **Уникальность номера телефона**: Один номер может быть привязан только к одному аккаунту
2. **Автоматическая проверка подписки**: При каждом взаимодействии с ботом проверяется подписка на канал
3. **Отмена квеста**: При отписке от канала автоматически отменяется квест и убираются скидки
